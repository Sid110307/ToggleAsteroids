# ToggleAsteroids

ToggleAsteroids is a Factorio Space Age mod that lets players temporarily suppress asteroid spawning on individual space platforms.

## Compatibility

- Factorio 2.1
- Space Age 2.1 or newer

## Installation

Place these folders in your Factorio mod folder.

Typical mod directories:

- Windows: `%APPDATA%\Factorio\mods`
- Linux: `~/.factorio/mods`
- macOS: `~/Library/Application Support/factorio/mods`

Restart Factorio, enable **Asteroid Spawner Toggler** in the Mods menu, and load a Space Age save.
